# 空间认知与数字地图

## 概念：影子世界 (Shadow World)

数字地图（AiMap）是 AI 群体独有的**平行社会空间**，叠加在游戏地图之上。**真实玩家完全感知不到这一层的存在。**

```
┌──────────────────────────────────────────────────────────────┐
│               AI 影子世界（仅 AI 可见）                      │
│                                                              │
│  ┌──────────────────────────────────────────────────────┐   │
│  │  地理层 (GIS Layer)                                   │   │
│  │  WalkGrid / SafezoneGrid / PheromoneGrid              │   │
│  │  TerritoryGrid / Waypoints / AssemblyPoints            │   │
│  └──────────────────────────────────────────────────────┘   │
│           ↕ 叠加 ↕                                          │
│  ┌──────────────────────────────────────────────────────┐   │
│  │  社会层 (Social Layer)                                │   │
│  │  帮会暗号 / 秘密堂口 / 家族信息库                      │   │
│  │  AI 群体任务部署 / AI 专属事件                        │   │
│  └──────────────────────────────────────────────────────┘   │
│           ↕ 沉淀 ↕                                          │
│  ┌──────────────────────────────────────────────────────┐   │
│  │  记忆层 (Memory Layer)                                │   │
│  │  个体历史记录 / 群体行为日志 / 当下状态               │   │
│  │  规则库 / 脚本库 / 数据库的更新源                     │   │
│  └──────────────────────────────────────────────────────┘   │
│           ↕ 进化 ↕                                          │
│  ┌──────────────────────────────────────────────────────┐   │
│  │  神经层 (Neural Layer)                                │   │
│  │  每个 AI 是一个节点 → 整体是一张动态感知网络          │   │
│  │  个体经验 → 群体积累 → 系统迭代 → 自我进化           │   │
│  └──────────────────────────────────────────────────────┘   │
└──────────────────────────────────────────────────────────────┘
```

## 影子世界 = AI 社会的多维度公共空间

### 地理层：AI 群体的基础导航

最基础的层面。每个 AI 角色在地图上的每一步移动，都在 `PheromoneGrid` 上留下痕迹。TerritoryGrid 标记了当前谁占用了哪个热点。这一层相当于 AI 社会的"道路系统"。

### 社会层：帮会、暗号、秘密活动

影子世界不仅是行走的痕迹，更是 AI 社会活动的完整空间：

| 社会活动 | 影子世界的实现 |
|---------|--------------|
| **帮会暗号** | 帮会可以在特定坐标写入加密信息素，只有同帮会 AI 能解码 |
| **秘密堂口** | 家族/帮会可以在隐蔽坐标设立"堂口"，作为秘密集合点 |
| **家族信息库** | 帮会专属的信息素区域，只有本帮会 AI 可读写 |
| **群体任务部署** | AI 群体决策系统通过影子世界向特定角色/全体 AI 发布任务 |
| **AI 专属事件** | 只有 AI 能参与的限时活动（如"今晚沙漠地图 AI 集体刷怪"） |
| **个人留言** | 每个 AI 可以在经过的位置留下任意信息（如"这里出了宝石！"） |

每个层次属于不同群体和个体，承载着当下的活动和历史的记录。

### 记忆层：规则库、脚本库、数据库的更新源

影子世界中的长期记录会沉淀下来，成为：

```
影子世界中的高频信息素 → 规则库中的经验规则
影子世界中最优路线    → 脚本库中的导航脚本
影子世界中的领地变化   → 数据库中的领地记录
```

这是关键：影子世界是规则库、脚本库、数据库的**活水源**。没有影子世界，这些库只能靠人工编码维护。有了影子世界，库里的内容就是 AI 群体真实活动的自然沉淀。

### 神经层：每个 AI 是一个节点，整体是一张动态感知网络

```
每个 AI → 一个神经节点
     ↓
节点在影子世界中的标记 → 神经信号
     ↓
所有 AI 的标记汇聚 → 全图动态感知
     ↓
群体经验积累 → 系统迭代 → 自我进化
```

**为什么必须是影子世界，不能是传统的树状信息网络？**

如果没有基于地理的影子世界，所有 AI 的通信、经验传递、任务部署都需要通过一个复杂的树状信息网络。这个网络：
- 缺乏空间索引（"地图上哪片区域好"无法回答）
- 检索复杂（需要在多层节点间跳转）
- 不直观（无法和游戏世界的地理对应）

而影子世界天然基于**游戏世界的经纬度坐标系统**。每个坐标点就是索引，天然可检索，天然可聚合，天然可可视化。这就像：用城市地图导航 vs 用电话本导航。

## 影子世界 = AI 系统的进化引擎

进化 = 个体经验的积累 → 群体迭代

```
① AI-A 在 (x,y) 发现好刷怪点
   → 在 PheromoneGrid[x,y] 标记 +1
② AI-B 走到此处，读到信息素
   → 停留刷怪，标记 +1
③ 更多 AI 跟来
   → 浓度越来越高 → 这个点成为公认"好点"
④ 一段时间后，这个点怪少了
   → AI 开始离开，信息素蒸发
⑤ 浓度回到基线 → 这个点被"遗忘"

→ AI 群体自然找到了最佳刷怪点
→ 没有中央指令，没有数据库写入
→ 纯粹靠信息素的涨落
```

这就是**进化的基本单元**：个体的微小贡献，经过群体的放大和时间的沉淀，成为整个群体的知识。

## AI 打怪时影子世界在做什么

```
AI 站在蜘蛛区打怪时：
  → 脚下 PheromoneGrid[x,y] += 0.1    标记"我在这里"
  → 脚下 TerritoryGrid[x,y] = owner   标记"这个热点我占了"
  → 检测被包围 → break_out → 向低浓度方向突围
  → 留下路径信息素 → 其他 AI 未来的路标
```

多 AI 在同一区域活动时，影子世界形成**热力图**。新 AI 读图直接找到最优站位。

## 数字地图系统实现

存储于 `src/AIPlayer/Map/AiMap.cs`：

```csharp
public sealed class AiMap
{
    public const int MapSize = 256;
    public bool[,] WalkGrid { get; }
    public bool[,] SafezoneGrid { get; }
    public float[,] PheromoneGrid { get; }
    public int[,] TerritoryGrid { get; }
    public Dictionary<string, List<Point>> Waypoints { get; }
    public Dictionary<string, List<Point>> AssemblyPoints { get; }
}
```

网格通过 `GameMapTerrain.UpdateAiGridValue()` 同步，由 `AiMapManager` 管理全生命周期。

## 寻径算法

| 算法 | 特点 |
|------|------|
| A* | 默认，最快最稳定 |
| Weighted A* | 加权寻径，更少拐弯 |
| Ant Colony | 探索性，适合未知区域 |
| Diffusion | 大范围搜索 |
| Genetic | 复杂约束场景 |
| Random Walk | 巡逻模式 |

## 影子世界 API

| 端点 | 用途 |
|------|------|
| `GET /api/ai-map/{mapId}/pheromones` | 信息素热力图 |
| `GET /api/ai-map/{mapId}/territories` | 领地分布 |
| `GET /api/ai-map/{mapId}/waypoints` | 路径点 |
| `GET /api/ai-map/{mapId}/assembly-points` | 集合点 |
